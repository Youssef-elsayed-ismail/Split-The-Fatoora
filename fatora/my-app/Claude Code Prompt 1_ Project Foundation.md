Build the initial version of a web app called **Split Fatoora**.

Goal: a simple receipt-splitting app where users upload a receipt, extract items and charges, assign items to people, and calculate each person's share.

Tech:
- Use the existing project stack.
- Use TypeScript.
- Keep components modular.
- Keep calculation logic separate from UI.
- Make the app responsive, especially for mobile.
- Do not add authentication, payments, database, chat, or unnecessary features.

Design:
- Minimal, modern, clean UI.
- White/light neutral background.
- Rounded cards.
- Clear typography.
- Subtle animations only.
- One obvious primary action per screen.
- Avoid dashboards and excessive UI.

Create the basic app structure and these routes/screens:

1. Home
2. Receipt Review
3. People
4. Item Assignment
5. Results

Use mock receipt data for now so the entire flow can be tested.

Do not implement OCR yet.

After implementation, check that the app runs without errors.
